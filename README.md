# Colab Playground: AutoML, Clustering and GPU Data Science

A collection of Google Colab notebooks covering AutoGluon, PyCaret, K-Means
clustering and NVIDIA RAPIDS. Each notebook has short narration cells added
beside the code, explaining what each step does and why, and each one is
paired with a short walkthrough video.

[**Find rest of my assignments here**](https://github.com/jahgath/CMPE-255-Data-Mining)

## Notebooks and Videos

Every notebook is in the [`kmeans-clustering`](https://github.com/jahgath/kmeans-clustering) repo, run end to end with outputs saved.
Each video is a walkthrough of one notebook, hosted on Google Drive.
